Before running the code we will need to install all the required libraries first in a virtual environment:
create a virtual environemnt for libraries
    1. open terminal (command prompt)
    2. enter "python -m venv myenv" (creating the virtual environment)
    3. enter ".\myenv\Scripts\activate" (accessing the myenv virtual environment)
    4. enter "pip install -r .\Big_Data\requirements.txt" (This will install all the libraries needed in the program)

p.s. due to the nature of pyspark, every time we run the code we will need to restart the session
